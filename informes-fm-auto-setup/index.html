Carga de Informes FM Ciudad Automática

Una sola configuración. Después: WhatsApp → compartir foto + audio → el sistema analiza, sube a Drive y actualiza el Word sin abrir ninguna web.

1Tu clave privada

Esta clave se genera únicamente en tu navegador. No se guarda en esta página ni en GitHub.

2Crear el Apps Script

Entrá con ciudadfm89.7@gmail.com a script.new y creá un proyecto llamado Carga de Informes FM Ciudad Automática.

Después reemplazá todo el contenido de Code.gs por el código de abajo.

Cargando código…

3Conectarlo al proyecto de Google

En Apps Script: Configuración del proyecto → Proyecto de Google Cloud → Cambiar proyecto.

Usá este número de proyecto: 242853096419

Es el mismo proyecto gestor-informes-fm-ciudad donde ya están habilitadas Drive API y Generative Language API.

4Pegar el manifiesto

En Configuración del proyecto activá Mostrar el archivo de manifiesto appsscript.json en el editor. Volvé al editor, abrí appsscript.json y reemplazá todo.

Cargando manifiesto…

5Autorizar una sola vez

En el selector de funciones de Apps Script elegí autorizar y tocá Ejecutar. Elegí la cuenta de FM Ciudad y aceptá los permisos solicitados.

Esto es lo que permite que el script trabaje después aunque no tengas abierta la app.

6Publicar como aplicación web

Apps Script → Implementar → Nueva implementación → Aplicación web.

Ejecutar como: Yo
Quién tiene acceso: Cualquiera

Implementá y copiá la URL que termina en /exec.

7Crear el Atajo automático

Duplicá el Atajo actual y llamalo Carga de Informes FM Ciudad Automática. El original queda intacto.

Después de Crear archivo .zip:
1. Agregá Codificar en Base64 usando Archivo comprimido.
2. En Obtener contenido de URL pegá la URL /exec de arriba.
3. Método: POST.
4. Cuerpo: JSON.
5. Campo token → pegá la clave privada de esta página.
6. Campo zip_base64 → variable Texto codificado en Base64.
7. Después: Obtener valor de “message” en Contenido de URL → Mostrar notificación.

Resultado

Cuando esté listo, compartirás 1 foto + 1 audio desde WhatsApp y recibirás una notificación como: “Informe 07 procesado y guardado en Drive.”

La versión manual que ya usás sigue funcionando como respaldo y no se modifica.
